# Changelog

## v0.8.0 (2026-06-03)

- Implemented comprehensive handler registry for 20+ file formats.
- Added syntax highlighting for source code, JSON, YAML, TOML using Chroma.
- Added CSV rendering using Lipgloss tables.
- Added structured rendering for XML and HTML.
- Added Markdown rendering via Glamour.
- Added Directory listing and Symlink handlers.
- Added smart archive listing for zip, tar, tar.gz, rar, 7z.
- Added PDF, DOCX, XLSX, PPTX, ODT text extraction parsing.
- Added Audio, Video, Image metadata rendering and previews.
- Added X.509 Certificate and SSH key parser.
- Setup GitHub Actions for CI and GoReleaser.

## v0.1.0 (2026-06-03)

- Initial scaffolding of `asd` universal file viewer.
- Setup Cobra CLI, Config loader, Pager support.
